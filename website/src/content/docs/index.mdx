## What you get

<CardGrid>
	<Card title="Typed jobs" icon="approve-check">
		A `Pool[T]` queues values of type `T`, and a worker is a `func(T)`. The compiler checks them: no
		reflection, no `interface{}`.
	</Card>
	<Card title="Backpressure" icon="warning">
		When the queue is full, `Delegate` waits for room and gives up when its context is done, so a
		deadline bounds the wait.
	</Card>
	<Card title="Graceful stop" icon="close">
		`Stop` runs the queued jobs on the workers left and returns once they have exited. After it, `Delegate`
		returns `ErrStopped`.
	</Card>
	<Card title="Workers at any time" icon="puzzle">
		Add a worker whenever you like, each with its own func. `AddWorker` returns the func that
		removes that worker.
	</Card>
	<Card title="Lean" icon="rocket">
		Queueing a job into a queue with room and running it on a worker allocate nothing, and tests guard
		the allocation counts.
	</Card>
	<Card title="Deterministic tests" icon="clock">
		Tested in `testing/synctest` bubbles: fake time, no sleeps, no leaked goroutines, 100% coverage.
	</Card>
</CardGrid>

## Faster than v2, with no allocations

<div class="landing-lead">
	v2 built a slice of reflect values for every job and called the worker through reflection. v3 sends a typed
	value on a channel and calls the worker's func directly. A job through one worker went from 216 ns to 39 ns.
	With 16 callers at once, the time is wall time per call across all of them, so it measures throughput.
</div>

## Coming from v2

<div class="landing-lead">
	The idea is the same, with types: a job is a <code>T</code> and a worker a <code>func(T)</code>. A worker is
	removed with the func <code>AddWorker</code> returns, <code>Delegate</code> takes a context, and
	<code>Stop</code> finishes the queue.
</div>

<div class="compare">

```go title="v2"
pool := workerpool.New(100)
worker := func(path string) {
	resize(path)
}
_ = pool.AddWorker(worker)

_ = pool.Delegate(path)
_ = pool.RemoveWorker(worker)
```

```go title="v3"
pool := workerpool.New[string](100)
remove := pool.AddWorker(resize)

_ = pool.Delegate(ctx, path)
remove()
```

</div>
